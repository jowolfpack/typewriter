# Local texts

Same rules as `texts/`: drop a `.txt` in `en/` or `de/` and it shows up.

The difference is that `.gitignore` keeps everything in here out of the
repository, so these texts work on this machine and are never published. This is
where a copyrighted book, a work document, or anything private belongs.

The folders are committed (empty) so the build has something to look at; the
files in them are not.
